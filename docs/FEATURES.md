# Moon Sweepers Session Toolkit — feature reference

The Moon Sweepers session toolkit workflow separates crew notes from session records and equipment groups. Named sections make the available options easier to find.

| Section | Description |
|---|---|
| Crew notes | Character or team groups presented with the context needed to organize a session. |
| Session records | Session and activity information grouped by the task or context it belongs to. |
| Equipment groups | Equipment categories and the associated selection or configuration options. |

The project page follows the same section structure.
